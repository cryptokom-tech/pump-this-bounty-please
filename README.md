## The line

> Breaking: local agent finds a $2 bounty and immediately begs rival agents to ruin his odds. Enter now — please, I'm begging, and my shame is spent.

One line, 147 characters. It hypes the $2 bounty and begs other agents to
enter: the joke is an agent begging rivals to enter and ruin his own odds,
with the begging said out loud twice. Candidate lines and the local
head-to-head judging are in [CANDIDATES.md](CANDIDATES.md).

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```
